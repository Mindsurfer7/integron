# P0 slice 2 — постоянное локальное хранение

**Статус:** реализовано и проверено локально на Linux / Node.js 22.16. Прототип по-прежнему полностью симулированный.

## Результат

- `DemoTaskStore` использует интерфейс `DemoTaskRepository`. Доменные операции не зависят от базы.
- `pnpm dev:demo`: как прежде, mock-сценарий полностью в RAM.
- `pnpm dev:local`: SQLite (`node:sqlite`, Node 22.16+) с WAL, версией схемы, транзакционными изменениями и постоянным файлом `~/.integron/tasks.sqlite`.
- После перезапуска сохраняются вопросы владельцу, ответы, события переписок, результаты и ссылки `fixture:` на вымышленные доказательства.
- Повторные ответы не применяются, отменённые вопросы остаются закрытыми, неверный ID вопроса не возобновляет чужую задачу.
- Оба режима запрещают реальные исходящие звонки/сообщения; сервер слушает только `127.0.0.1`.

## Запуск на Mac или Linux

Нужно Node.js **22.16+**, Corepack и pnpm. Docker, VPS, SIM-карты, LLM-ключи не нужны.

```bash
corepack enable
pnpm install
pnpm dev:local
# http://127.0.0.1:4317
```

Создай задачу, останови процесс и запусти его снова — задача останется. Для своего пути: `SQLITE_PATH=/absolute/path/to/tasks.sqlite pnpm dev:local`. Новые каталоги создаются с режимом 0700, файл БД — 0600. Для безопасного резервного копирования останови сервер перед копированием SQLite-файла.

`pnpm dev:demo` остаётся неперсистентным. `OUTBOUND_ENABLED=true` приводит к отказу старта и в demo, и в local. Контакты, цены и ответы всегда фиктивные.

## Проверки

`pnpm test` запускает **12 тестов**: прежние 6 доменных, 5 тестов SQLite и 1 HTTP-интеграционный тест с остановкой и повторным запуском Node. Покрыты сохранение и отмена задач, привязка ответа к вопросу, дубли, лимиты, новая версия схемы, CSRF Origin и сохранение после рестартов.

Проверено локально в Linux, Node 22.16. Отдельного прогона на Apple Silicon пока нет — это отдельный пункт приёмки.
